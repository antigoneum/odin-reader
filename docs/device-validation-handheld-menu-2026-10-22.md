# 0.3.0 横向掌机菜单验证

日期：2026-10-22；设备：Odin 3 / Android 15，横屏 1920 × 1080。

## 变更与操作

- 顶部“书库 / 设置 / 操作指南”横向菜单；L1 / R1 立即切换并循环，左右方向移动焦点、A 确认选页。
- 向下进入当前页面内容；导入按钮或设置、指南返回按钮可向上回到对应菜单项。
- 书籍按横向书架排列，方向键和摇杆左右选择；B 从设置或指南返回书库。
- 阅读中的 L1 / R1 继续翻页；阅读设置继续使用覆盖层，保留原有返回和按键映射规则。
- 按钮和书卡使用明确的 shape，焦点描边复用同一 shape 并绘制在实际控件尺寸内；按钮至少 48dp 高，消除最小触摸区域导致的错位。

## 验证结果

- Debug 应用和 Android 仪器测试 APK 构建成功。
- JVM：38 项通过，0 失败。
- Android 仪器测试：31 项通过，0 失败，耗时 19.514 秒。
- Lint：0 错误、22 项警告。
- 同签名覆盖安装版本 0.3.0（versionCode 3）。
- 设置、阅读进度的 XML 键值与本轮测试前备份一致；测试不删除原书籍。

新增三项菜单回归覆盖肩键循环、设置/指南 B 返回书库、触摸选页、方向焦点与 A 确认，以及 Activity 重建后的所选页面恢复。原有 28 项测试继续通过，包括摇杆/十字键进入导入按钮、横向书架导航、阅读肩键翻页、主题与改键、PDF 阅读和恢复。

使用 ADB 来源为 gamepad 的 R1 事件实际切换并检查书库、设置、指南截图；通过 dpad 方向事件选中书卡，确认焦点描边与圆角相合。截图和运行日志保存在本地忽略目录 `artifacts/handheld-menu-2026-10-22/`。
